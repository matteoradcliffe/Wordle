# Wordle

## Overview
A Java implementation of the popular Wordle word game developed as part of a software engineering course. The project follows the Model-View-Controller (MVC) architecture and emphasizes object-oriented design, testing, and maintainable code.

## Features
- Playable Wordle game
- Word validation
- Color-coded feedback
- MVC architecture
- JUnit unit testing

## Tech Stack
- Java
- Swing
- JUnit

## What I Learned
- Object-oriented programming
- MVC software architecture
- Unit testing with JUnit
- Software design principles
